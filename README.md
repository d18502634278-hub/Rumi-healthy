# わんログ（iPhone用アプリ）

犬のおしっこ・うんち・水・エサを記録するアプリです。
App Store を使わず、iPhone のホーム画面に追加して、普通のアプリのように使えます。

## このフォルダの中身

- `index.html` … アプリ本体
- `manifest.webmanifest` … アプリ名やアイコンの設定
- `sw.js` … オフラインでも開けるようにする仕組み
- `icon-*.png` / `apple-touch-icon.png` … アイコン

## 使えるようにする手順

ホーム画面に追加するには、このフォルダを **https で開けるWebサイト** に置く必要があります。
無料で使える静的ホスティング（GitHub Pages、Netlify、Cloudflare Pages など）のどれかに、
フォルダの中身をそのままアップロードしてください。

1. 上のサービスのどれかに、このフォルダの中身をアップロードします（フォルダごとではなく、中のファイルを直下に置きます）。
2. 発行されたURL（`https://〜`）を iPhone の **Safari** で開きます。
3. 画面下の共有ボタン（□に上向き矢印）を押します。
4. 「ホーム画面に追加」を選び、「追加」を押します。

ホーム画面の「わんログ」から起動すると、アドレスバーのない全画面で開きます。
一度開いたあとは、電波がない場所でも使えます。

## 記録の保存について

- 記録は **その iPhone の中だけ** に保存されます。サーバーには送られません。
- ホーム画面のアイコンを削除すると、記録も消えます。
- 機種変更や削除に備えて、「履歴」タブの下にある「書き出す」でときどきバックアップしてください。
  新しい iPhone では「読み込む」で戻せます（同じ記録は重複しません）。
- 複数の iPhone で同じ記録を共有する機能はありません。

## App Store で配布したい場合

この形式とは別に、本物の iOS アプリとして作る方法もあります。
Mac と Xcode、Apple の有料開発者登録（Apple Developer Program）が必要です。
このアプリを Capacitor という仕組みで包めば、同じ画面のまま iOS アプリにできます。
